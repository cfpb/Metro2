## Admin vs non-admin users

Both admin and non-admin users can use the Metro2 application to view Metro2 event data for events they are assigned to.

Admin users have access to the administrator view of the Metro2 application. Admin users have the ability to:
- Create and update event records
- Assign and un-assign users to events
- Add and modify evaluator metadata
- Deactivate and re-activate users
